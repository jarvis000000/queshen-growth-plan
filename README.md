# 雀神成长计划 · 温州麻将技巧训练

一个以**教学**为核心的温州麻将人机对战练习工具。三档 AI 对手、实时出牌胜率分析、对手牌型推断。

## 运行

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm test         # 引擎与对局模拟测试
npm run build    # 生产构建
```

## 规则实现

按本地 16 张打法实现，关键规则均落在引擎层：

| 规则 | 说明 |
| --- | --- |
| 牌池 | 万筒条各 36 + 东南西北各 4 + 中发白各 4，共 136 张，无花牌 |
| 手牌 | 庄家起手 17 张，闲家 16 张；胡牌为 **5 组面子 + 1 对将（17 张）** |
| 财神 | 开局从牌墙翻出一张确定。财神牌为万能牌，可作任意牌（含其本身） |
| 白板 | 等效于**财神原牌**，且该等效贯穿吃、碰、杠、胡全部牌型判定 |
| 财神为白板时 | 白板升格为万能牌本体，无替代关系 |
| 吃 | 仅限下家；优先级 胡 > 杠 > 碰 > 吃 |
| 杠 | 支持明杠、暗杠、加杠，杠后从牌墙补牌；暗杠财神等于钉死万能牌，AI 主动回避 |
| 有风跟打 | 牌河末张为字牌、且手中该种牌恰好一张时必须跟打该张。成对成刻的字牌能组成面子，不拆；无跟打目标时自由出牌。财神是万能牌，不构成跟打目标、也不会被强制打出 |
| 特殊牌型 | 三财神直接胡、八对、碰碰胡、清一色、混一色、门清 |
| 计分 | 底分 × 倍数（软牌 1 / 硬牌 2 / 双翻 4）+ 财神分；软硬由财神是否归位判定 |

### 财神与白板的引擎模型

白板在非财神局面下直接折算进 `counts[财神原牌]`，财神牌单独计为万能牌计数。这样后续所有算法只需面对
「本色牌 + 万能牌」两种输入，白板可吃碰杠胡的规则自然成立，无需在各处重复判断。

## AI 不作弊的架构保证

AI 决策只接收 `PlayerView` 结构，其中**不包含任何其他玩家的手牌**，仅含自己的手牌、四家牌河、四家副露、
牌墙剩余数与财神。其他玩家的暗牌在类型层面即不可达。

三档难度差异：

| 难度 | 评分依据 | 失误率 | 防守 |
| --- | --- | --- | --- |
| 简单 | 仅看打后向听数 | 40%（可偏离至第 5 优） | 无 |
| 普通 | 向听数 + 有效进张 | 12%（可偏离至第 3 优） | 有 |
| 雀神 | 向听数 + 有效进张 + 危险度 | 0 | 完整读牌 |

## 教学功能

教学功能均可在**设置**中独立开关，关闭后即为纯对局模式：

### 摸鱼模式

设置中开启后收起图形牌桌，整页变成一份**白底等宽字体的对局记录**，用命令行交互，适合不便显示牌桌的场合。
文字界面与图形界面共用同一套对局与教学引擎，功能完全对等。

**小窗悬浮**：点右上角「小窗」可将整个界面移入 **Document Picture-in-Picture** 窗口——一个始终置顶的小窗，
能悬浮在文档、编辑器或其他窗口之上，一边看资料一边对局。关闭小窗或按「退出」即自动收回主页面。
该 API 目前仅 Chrome / Edge 116+ 支持，其他浏览器会给出提示。注意刷新主页面会遗留下一个失效的小窗，手动关掉即可。

**自己的牌常驻顶部**：手牌、副露、牌河与对手概况固定在日志上方，不随记录滚动，随时可见
（财神牌标 `*`、白板标 `^`）。

**能否打出直接看颜色**：轮到出牌时，可打出的牌显示为绿色、受「有风跟打」限制的牌转灰、
财神显示为金色，不再单独占一行；方向键选中或手动输入的牌以琥珀底高亮，同种牌有几张就一起点亮。

**新摸的牌与响应高亮**：刚摸到的牌单独排到手牌末尾并加下划线，不与已理顺的牌混在一起；
进入吃碰杠响应时，当前选项要用到的牌同样会在手牌中高亮。

**日志实时记录四家动向**：每次打出牌、每次吃碰杠都会即时写入记录，形如

```
下家 打出 东
上家 碰 [8筒 8筒 8筒]
上家 打出 8筒
你 打出 北
下家 胡牌（放炮者 上家）：1万
```

自己的操作标蓝，他家标黑，便于快速扫读。

**方向键随情境切换**：正常出牌时在可打出的牌之间循环；一旦进入响应状态（可碰/吃/杠/胡），
方向键改为在**响应选项**之间循环；一局结束后则只在**重开 / 退出**之间循环。
存在多种吃法时，填出的命令会带上具体牌张（如 `吃 3筒 4筒`），以免两种吃法无法区分。

命令一览（游戏内输入「帮助」亦可查看）：

| 命令 | 作用 |
| --- | --- |
| `<牌名>` | 打出该牌，支持「5万」「五万」「5m」「东」等写法 |
| `←` `→` `↑` `↓` | 在可打出的牌或响应选项之间循环，自动填入命令行 |
| `建议` / `t` | 列出每张可打牌的胜率、听牌进度、进张与危险度 |
| `分析 下家` | 查看某家牌型推断（下家 / 对家 / 上家） |
| `碰` / `吃 3筒 4筒` / `杠 5万` / `胡` / `过` | 响应他家打出的牌 |
| `手牌` / `h` | 重新显示手牌与当前可打牌 |
| `重开` / `退出` | 换一局 / 返回图形界面 |

摸鱼模式下**不拦截偏离最优解的出牌**，改为在出牌后补上教学：明显偏离时自动列出全部可打牌的
胜率对比，轻微偏离时只提示与最优解的差距，保持输入节奏的连贯。该提示同样受设置中的
「出牌胜率提示」开关控制，关闭后不再输出。

### 键盘操作（图形界面）

| 按键 | 作用 |
| --- | --- |
| `←` `→` | 在**可打出的牌**之间移动光标（跳过受「有风跟打」限制的牌） |
| `↑` | 提起当前牌 |
| `↓` | 放下 |
| `空格` / `回车` | 打出提起的牌（未提起时为光标所在牌） |
| `←→↑↓` + `空格` | 吃碰杠与自摸弹窗中选项的切换与确认，`Esc` 放弃 |

### 悬停即时胜率

鼠标移到任意手牌上，立即浮出该张的：

- 胜率百分比与排名（如「第 3 选 / 共 5 张」）
- 是否为当前最佳出牌
- 打出后的向听数与有效进张张数

受「有风跟打」限制不可打出的牌，会明示不可打的原因。

### 出牌胜率分析

玩家打出的牌若非最优解且分差达到阈值，会弹出对照表，列出**每一张可打牌**的：

- 相对胜率（由打后向听数、有效进张张数、对他家危险度折算）
- 打出后的向听数、有效进张张数与具体进张牌
- 对他家的危险度
- 理由文字（为何更优、差在哪里）

玩家可直接改打推荐牌，或坚持原选择。

### 对手牌型推断

点击任意对手（或"分析下家/对家/上家"按钮）可得：

- 疑似听牌概率、牌型方向判断（一色牌倾向、副露速度）
- 危险牌排行及逐张理由（现物、筋线、副露同花色、中张等）

## 核心算法说明

带万能牌的胡牌判定与向听数都采用**锚定最小非零牌**的递归搜索：该牌若入面子，必为刻子成员或以它开头的
顺子；它作为顺子中张或末张时所缺的前置牌只能由万能牌补，与「本色刻子 + 万能补位」消耗等价，故无需枚举，
搜索空间由此收敛。

向听搜索使用两类剪枝：满分即牌型成立时立即终止；乐观上界按**面子的最高密度（2 分 / 3 张）**估算——若按
1 分 / 2 张估算会低估并错误剪掉带财神的最优解。

## 已知限制

- 买底分、顶底分、连庄递增等玩家操作类计分未实现，仅计算基础分与财神分
- 未实现抢杠胡（他家加杠时不可抢胡）
- 单次完整出牌评估约 100-300ms（视可选牌数而定），当前在主线程计算；如需进一步提速可将评估迁入 Web Worker
- 对手推断为启发式模型（筋牌、副露花色、巡目），非精确贝叶斯推断
